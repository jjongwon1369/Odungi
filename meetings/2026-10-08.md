# 9차 회의록 (팀)

| 항목 | 내용 |

| 일시 | 2026년 10월 8일(목) 18:00 ~ 20:00 |
| 장소 | 오프라인, W커넥션 |
| 참석 | 박종원, 김태이, 정채희, 이동수 |
| 불참 | 멘토 오재덕 책임연구원 (오늘 미팅 없음) |

> **한 줄 결론:** 팀원 초안을 합친 논문을 함께 읽고 피드백을 모았다. **논의를 빼고 결론을 강화**하고, **청구액은 빼고 토큰 사용량만** 쓰기로 했다. 반영본은 노션에 올려 멘토님께 **금요일(10/9)까지** 피드백을 받는다.
> 


진행 순서

1. 합본 확인 (박종원)
    - 팀원 초안을 KSC 양식에 맞춰 합친 3쪽 합본 공유, 사사 문구 포함본도 준비
    - 형광펜 표시본으로 팀원별 확인 사항 공유
2. 논문 피드백 (팀원별)
    - **정채희**
        - A·B·C 구축 과정이 빠짐 → '비교 시스템'을 '시스템 구축'으로 바꾸고 A·B·C 구축 과정을 각각 서술
        - 2.3 공통 조건에 쓴 모델명을 구체적으로 적고, **참가자 모델 7종의 답변 비교 표** 추가
        - 2.1의 평가 질의 40개 구성은 선행논문처럼 **표로** 정리
        - AI 말투 정리: "글자 단위로 공유", 서론의 "~로 판정된다"
    - **이동수**
        - **논의를 빼고 결론을 확실하게** 채우기 (논의와 결론이 같은 말 반복)
        - 3.1의 ①②③ 번호 매김이 어색함, 3.2 범위 표기 일관성(대괄호·쉼표 vs 물결)
        - 제목은 Matter인데 **결론에 Matter 내용이 없음** → 결론에 Matter 언급
        - 모델별·시스템별 평가 결과 표 필요
    - **김태이**
        - 서론에 Matter를 먼저 언급하고 **각주**로 설명 (서론 첫머리 "사양 XML, SDK 코드 생성 정의"가 처음 읽는 사람에게 어려움)
        - 서론 마지막 기여 문단 삭제, "이에 본 연구는~"은 2장으로 이동
        - 3.3 "~로 보인다"처럼 **실험으로 확인하지 않은 주관적 해석 금지** → 표현을 바꾸거나 삭제
        - **표에 이미 있는 숫자는 본문에서 반복하지 않기** (3.2 신뢰구간처럼 표에 없는 것만)
        - "F1" → "**F1 점수**"
        - 기호 표기 통일 (점·대시 혼용 등)
    - **3.3 식별자 정확성**: 불일치 ID가 몇 건 중 몇 건인지, 비율이 무엇의 비율인지 잘 안 읽힘 → 수식어를 붙여 명확하게
3. 구성 변경 (합의)
    - 2.1은 **코퍼스**만 남기고, 평가 질의 내용은 **3.1 평가 방법에 합병**하여 표로 정리
    - 평가 질의 구성 표는 질의 유형별 결과와 연결되도록 배치
    - 4장 논의 삭제 → **'결론 및 향후 연구'** 하나로 통합하고 내용 보강 (질의 유형별 결과, 신뢰도, 멘토님 후속연구 제안 포함)
4. 토큰 사용량 vs 청구액
    - 초안 4.2에 있던 청구액(2.9배)이 합본 요약본에서 빠짐 → 넣을지 논의
    - 청구액 찬성: 기업은 결국 비용(돈)을 본다
    - 반대: 모델·제공사마다 토큰 단가가 다르고, 단가가 수시로 바뀌며(API 가격 변동), LLM 위키는 턴마다 사용량이 달라 환산이 번거로움 / 지면도 부족
    - → **청구액은 빼고 토큰 사용량만** 쓰기로 결정
5. 숫자 표기
    - 논문에서 "약"을 쓰는지 확인 → 근삿값보다 정확한 값으로 쓰기 (예: 1.8만 → 18,074)
6. 투고 부문 (학부생 vs 일반)
    - 학부생 부문: 우수상 가능성이 높고, "학부 때부터 논문을 썼다"는 점이 드러남
    - 일반 부문: '학부생' 꼬리표가 붙으면 경쟁 풀이 좁았다고 볼 수 있음 / 우수 세션에 뽑히면 구두, 아니면 포스터
    - 등록비는 두 부문 비슷(학생 10만 원 후반대 예상)
    - → 의견이 갈려 **멘토님께 다시 여쭤보기로** (졸업·진로 계획도 함께 말씀드림)
7. 멘토 피드백 방식
    - 오늘 멘토 미팅은 없음 → 반영본을 노션에 올리고 **금요일(10/9)까지** 노션 댓글이나 카톡으로 피드백 요청
8. 중간발표1 (10/15(목))
    - 발표 방향: **1차 중간 = 지금까지 한 일 + 논문 제출** / **2차 중간 = 논문 제출 후 포스터** / **최종 = 코퍼스 확장 등 후속 연구** (우수논문 대비)
    - 목차와 PPT 틀은 **박종원·정채희가 내일(10/9)까지** 발표팀에 전달
    - 영상 발표자: 가위바위보로 **이동수** 결정

결정 사항

- 4장 논의 삭제 → **결론 및 향후 연구** 강화 (Matter 언급, 질의 유형별 결과, 신뢰도, 코퍼스 확장·토큰 절감)
- 2.1은 코퍼스만, 평가 질의는 **3.1에 표로 합병**
- 2.2 '시스템 구축'으로 A·B·C 구축 과정 서술, 2.3에 모델 7종 명시 + **모델별 결과 표**
- 서론: Matter 각주, 기여 문단 삭제, "이에 본 연구는~"은 2장으로
- 주관적 표현 삭제, 표와 중복되는 숫자 삭제, "F1 점수"로 통일, 기호 통일
- 투고 부문은 멘토님께 재문의
- 중간발표 목차·PPT 틀 10/9까지 (Canva)
