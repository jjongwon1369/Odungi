진행 순서

**[팀 회의]**

1. 사람 검산 결과 공유 (박종원)
    - 박종원 58건 · 이동수 17건 검산, 겹친 15건은 **두 사람 판정 100% 일치**
    - 무작위 표본에서 **사람과 AI 심판 92% 일치**, AI 심판이 위키에 후했는지 의심되던 29건도 사람이 봐도 전부 정답
    - → AI 심판 결과를 믿고 논문에 쓸 수 있음
2. 결과 요약 (박종원)
    - 토큰: 위키가 RAG의 **약 4배** (선행논문은 21배)
    - **언제 무엇이 좋은가:** ID 하나를 찾는 질문은 RAG, 여러 문서를 엮어 설명하는 질문은 위키
3. 논문 초안 분담 (KSC 양식, 참고문헌 포함 2~3쪽)
    - 제목·요약 박종원 / 서론·관련 연구 정채희 / 실험 설계 이동수(코퍼스·질문)·김태이(A·B)·정채희(C) / 평가 방법·결과 박종원 / 논의·결론 김태이 / 참고문헌 이동수
    - **초안 작성**이고, 의견과 검수는 전원이 함께
4. 투고 부문 (일반 vs 학부생·주니어)
    - 학부생 부문: 학부생끼리 경쟁, 포스터 발표 / 일반 부문: 누구나, 구두 발표 가능
    - 정채희: 첫 논문이고 같은 상이면 학부생 부문에서 높은 상이 낫다
    - 김태이: 학회 발간 논문집으로 두 부문 수준을 비교해 보고 정하자
    - → 멘토님께 여쭙기로
5. 중간발표1 (10/22 → **10/15(목) 18:00**로 당겨짐, 시험과 겹치지 않게 됨)
    - 발표자: **김태이 · 이동수** (반씩 나눠 발표), 영상 발표자는 추후 결정
    - 대면 발표를 완성도 있게 준비해서 영상 촬영 때 수정을 최소화
    - 지난 발표의 아쉬움(틀을 먼저 나눠 끼워 맞춤) → 이번에는 역할을 단계별로 나눔
        - ① 목차 정하기 ② 발표자료 틀(프레임) 제작 → **박종원 · 정채희**
        - ③ 내용 채우기 · 대본 다듬기 → **발표 팀(김태이 · 이동수)**
        - 다음 발표 때는 역할을 바꿈

**[멘토 미팅]**

1. 결과 · 평가 방법 보고 (박종원)
    - 선행논문 대비 차별점: 기술문서 코퍼스, 정답 봉인, 원본 대조 자동 채점, 사람 검산
    - 세 겹 채점: 파이썬 자동 채점 → AI 심판(Claude · GPT) → 사람 검산
    - 멘토 질문: 심판은 몇 개인가 → 참가자 모델 7종이 답하고, **심판은 Claude · GPT 2개**
    - 멘토 의견: **신뢰도 측면은 확인됐다**
2. 투고 부문 — 멘토 의견
    - 실험·결과가 잘 나와서 **일반 부문으로 내도 문제없어 보이고**, 이왕이면 도전해 보는 것도 좋다
    - 다만 부문보다 **한 편의 논문으로 잘 구성되는 것이 더 중요**
    - 구두로 설명하고 싶으면 일반 부문, 포스터만 하고 싶으면 학부생 부문 → **팀에서 결정**
3. 후속 연구 제안 (멘토) → 논문의 '향후 연구'에 반영
    - **코퍼스 크기 확대:** 지금 코퍼스는 작음. 키우면 RAG와 위키의 격차, 위키를 써야 하는 조건이 더 분명해질 수 있음
    - **위키 구축 토큰 줄이기:** 위키는 처음 만들 때부터 토큰을 많이 씀
    - **컨텍스트 토큰 줄이기:** 검색 결과가 컨텍스트로 들어가며 쓰는 토큰
    - 업계는 모델 성능보다 **토큰 = 비용**을 본다. "좋은 건 알겠는데 토큰을 많이 먹으면 비교해 봐야 한다"
    - 단순한 조회는 RAG, 복잡한 질문은 위키나 그래프 기반 방식을 많이 쓰는 추세
4. 일정 · 지원
    - **10/4(일) 미팅 취소** → 초안을 쓰고 검수받는 것이 낫다
    - 10/8 전까지 초안을 노션에 올리면 멘토님이 검수 의견을 주심 (10/8 저녁 미팅은 멘토님 일정 확인 후)
    - 추가 실험에 LLM이 필요하면 추가 결제 가능

**[멘토 미팅 후]**

1. 정리
    - 초안을 다 쓴 뒤 멘토님께 투고 부문을 한 번 더 여쭙고, 작년 KSC 논문과 수준을 비교해 보기 (정채희)
    - 일반 부문에서 구두 발표가 필수인지 확인 (김태이)
    - 결과는 각자 파트를 쓰는 데 필요하지 않고 GitHub에 다 있으므로 별도 정리 없이 바로 초안 작성
    - 10월 말~11월 서울 대면 미팅(계획상 2회) 일정도 멘토님께 여쭙기
