## 2. 교과목 운영 안내 (김동균 교수님 / 조교)

### 2.1 과목 성격
- 캡스톤 디자인 과목으로, 기업이 제시한 과제를 팀 단위로 해결하는 **산업체 연계 프로젝트**.
- 물리적으로 출근하지 않는 인턴십에 준하는 경험으로 운영되며, 이후 현장실습과의 연계를 염두에 둠.
- 팀 인원은 타 분반과 공통으로 **최대 4명**.

### 2.2 멘토링
- **멘토와 주 1회 이상 회의**가 원칙. 멘토가 바쁜 경우가 많으므로 학생 측이 온라인 멘토링이라도 적극적으로 요청해야 함.
- 멘토링 관계에 문제가 생기면 학부에 피드백 → 학부가 직접 멘토와 접촉.
- 멘토링 내용은 **반드시 회의록으로 작성**하고, 사진·보고서·발표자료를 함께 남길 것.

### 2.3 GitHub 관리 (평가의 근거)
- 프로젝트 **수행 과정 및 결과물 전부를 GitHub에 업로드**해야 함.
- 대상: 소스코드, 기술 분석 자료, 회의 내용, 결과물.
- 이 기록을 기반으로 평가가 이루어지므로 누락 시 직접적인 감점 요인.

### 2.4 평가 방식
- **A 등급 약 50% 제한.** 같은 팀이어도 A와 B가 갈릴 수 있음.
- **팀원 상호평가(Peer Review)** 반영 — 무임승차 방지 목적.
- 상호평가 **담합(특정 팀에 몰아서 나쁜 점수 부여 등) 적발 시 0점 처리**.
- 필요 시 외부평가위원 평가 점수를 반영할 수 있음(미확정).
- 사소한 항목 하나로 A/B가 갈리므로 공지 확인·기한 준수가 중요.

### 2.5 발표 규정
- **발표 5분 + 질의응답 2분 = 총 7분. 시간 초과 시 감점.**
- **발표자를 고정하면 감점.** 팀원이 돌아가며 발표할 것.
- 교수님 질문은 잘잘못 평가가 아니라 **방향성 확인** 목적 → 답변 실패가 점수화되지 않음.
- 발표자료 금지 사항: **글 위주 슬라이드 금지, 코드 노출 금지.** 그림 중심으로 구성할 것.
- 발표 구성 권장: **기술 배경 → 문제 정의 → 기존 연구(또는 최초임을 증명) → 아이디어 → 계획**.
- 발표 태도: "숙제 검사"가 아니라 **다른 팀에게 우리 프로젝트를 소개한다**는 관점으로.

### 2.6 오프라인 발표 + 영상 발표 2단계 운영
1. 지정일에 **오프라인 발표** → 교수님·조교(외부위원 가능)가 평가.
2. 발표 후 **1주일의 유예 기간** 내에 교수님 피드백을 반영한 **발표 영상을 촬영·업로드**.
3. 업로드된 영상을 LMS 강의실에 게시 → **타 팀 학생들이 시청 후 상호평가**.
4. **영상 미시청 시 감점.** 평가지는 다음 수업에 지참(=출석 점수와 연동), 분실 시 스캔본·수기 작성본도 인정.
- 영상 발표를 별도로 두는 이유: 외부(기업) 인원이 오프라인 발표를 참관하기 어렵기 때문.
- 발표 언어는 한국어/영어 모두 허용(자막 첨부 사례 있음).

### 2.7 산출물 및 지원
- 최종 산출물: **보고서 + 논문**. 필요 시 특허·소프트웨어 등록.
- **특허·SW 등록은 반드시 사전에 조교에게 메일로 연락할 것** (과거 팀이 절차 미비로 실적을 인정받지 못한 사례 있음). 논문은 자유롭게 진행 가능.
- 기업 보안상 외부 공개가 불가한 과제는 논문 대신 다른 형태의 결과물로 대체.
- **공학논문 작성법 특강**을 수업 시간에 별도 진행 예정(시기 조율 중, 중간발표 즈음 유력).
- **논문에 사사(謝辭) 표기 필수** — 지원금 수령 조건.
- **학회 발표 지원**: 등록비 및 경비 1인 지원. 12월 제주도 개최 학회 다수, **11월 말 경북대에서 열리는 UCWIT** 등. 학회 목록은 조교가 정리해 공지 예정. 학생 논문은 통상 2페이지(서론·본론·결과 압축).
- **재료비 지원** 가능(안내 자료 기준 30만 원 수준, 별도 확정 예정). 집행 필요 시 사전 협의.
- **공간 지원**: DIY 실습실(리모델링 완료), 4층 회의실, 강의실 245호. 추가 공간 필요 시 요청 가능.

### 2.8 문의 창구
- **교수님께 직접 메일 보내지 말고 TA(조교)에게 먼저 연락.**

### 2.9 일정
- 발표 일정: **수행계획 발표 → (영상) → 1차 중간발표 → 2차 중간발표 → 최종 결과발표**.
- 현재 공지된 일정은 **변동 가능(대체로 1주 정도 순연되는 경향)**. 확정본은 추후 공지.
